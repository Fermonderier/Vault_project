# Этапы Liquidity Vault

Все этапы развивают программу и интерфейс в одном репозитории.

| Этап                | Результат                                                                                   | Статус                                            |
| ------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Каркас vault        | Vault PDA, отдельный strategy-authority PDA, token vault, share mint и профиль пользователя | Реализован                                        |
| Депозит и вывод     | CPI transfer, пропорциональные shares, блокировка во время стратегии                        | Реализованы; Rust-тесты пройдены                  |
| Настройка стратегии | Проверка Raydium pool и пары base/quote, начало и завершение стратегии                      | Реализовано; Devnet не проверен                   |
| Swap                | Raydium CPI с ограничением минимального output                                              | Реализован; нужен тест с реальным пулом           |
| CLMM-позиция        | Open/decrease/collect/close через Raydium CPI                                               | Реализовано; нужен тест с реальным пулом          |
| Devnet tooling      | Скрипты для двух test mint и пустого Raydium CLMM pool                                      | Реализовано; транзакции ещё не выполнялись        |
| Devnet acceptance   | Test pool с ликвидностью, позиция и Explorer доказательства                                 | Не выполнено                                      |
| Веб-интерфейс       | Подключение Phantom, баланс, shares, deposit/withdraw, статусы и admin UI                   | Реализован; нужен Devnet smoke test               |
| Demo Day            | Сценарий 5–7 минут и запасной план                                                          | Сценарий подготовлен; выступление не подтверждено |

## Порядок реализации

1. Запустить существующий integration test с локальным валидатором.
2. Развернуть программу в Devnet и сохранить адреса/транзакции.
3. Выполнить `npm run devnet:create-mints` и `npm run devnet:create-clmm-pool`; внести ликвидность и записать аккаунты пула.
4. Проверить UI, swap, slippage, открытие/снятие позиции, комиссии и закрытие на Devnet.
5. Провести репетицию по [сценарию демонстрации](demo.md).

На этапах Raydium использовать соответствующие официальные CPI-примеры и проверять program ID и аккаунты именно для devnet. Не подставлять фиктивные адреса в README и не считать симуляцию доказательством реального deploy.

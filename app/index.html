Raydium-инструкции

Для CPI укажите account map из IDL и данные пула. Общие PDA и программы можно подставить автоматически.

Какие данные нужны для CLMM CPI?

Для swap потребуются AMM config, observation state, оба pool vault/mint и tick-array accounts. Для позиции также нужны tick indexes, protocol position и NFT metadata PDA. Значения берутся из Raydium pool и официального SDK. Передавайте `minOutput`/минимумы с учётом slippage.
